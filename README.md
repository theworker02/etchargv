# etchargv

Etch CSV/TSV argv tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/etchargv/

## Install / run

```bash
git clone https://github.com/theworker02/etchargv.git
cd etchargv
node src/cli.js
node --test
```
